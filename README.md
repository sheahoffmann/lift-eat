# Lift & Eat

A home-screen web app (PWA) for workouts and nutrition, styled like an athlete in season.
Data stays on each phone (no accounts, no server).

- `npm run dev`: local dev server (also reachable from your phone on the same Wi-Fi)
- `npm run build`: production build into `dist/`
- Pushing to `main` deploys on Netlify (settings in `netlify.toml`)

Body map artwork adapted from [react-native-body-highlighter](https://github.com/HichamELBSI/react-native-body-highlighter) (MIT).
